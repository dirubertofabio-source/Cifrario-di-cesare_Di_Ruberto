# Cifrario-di-cesare
Programma in C++ che cifra una parola in base ad una chiave inserita da tastiera.

Per sintetizzare l'algortimo ho fatto in modo che la Chiave faccia spostare le lettere della parola inserita in precedenza di tante volte quanto dice la chiave,
Ho anche inserito un modulo di 26 così in questo modo se la chiave supera 26, ad esempio 30, ne farà il modulo semplifiicando lo spostamento.
Ho inserito 2 if così il programma fuznziona sia con le maiuscole che con le minuscole
